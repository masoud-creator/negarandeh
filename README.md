# نگارنده (Negarandeh) - محتواساز اتومات وردپرس مبتنی بر هوش مصنوعی 

نگارنده یک افزونه رایگان وردپرس مبتنی بر هوش مصنوعی است که به‌صورت خودکار مقالات باکیفیت، سازگار با اصول سئو و تصاویر شاخص را با استفاده از ارائه‌دهنده هوش مصنوعی دلخواه شما از طریق API تولید می‌کند.

با وارد کردن لیستی از موضوعات و پرامپت‌های اختصاصی خود، نگارنده می‌تواند به‌صورت خودکار نوشته‌های منحصربه‌فرد و آماده انتشار را در وردپرس ایجاد کند.

برخلاف بسیاری از افزونه‌های هوش مصنوعی، نگارنده **کاملاً رایگان** است و شامل هیچ‌گونه اشتراک، محدودیت استفاده یا خرید درون‌برنامه‌ای نمی‌باشد. تنها چیزی که نیاز دارید یک کلید API از سرویس هوش مصنوعی مورد نظر شما است.

# 🚀 چگونه کار میکند؟

1. کلید API ارائه‌دهنده هوش مصنوعی خود را وارد کنید.
2. پرامپت‌های اختصاصی برای تولید مقاله و تصاویر شاخص ایجاد کنید.
3. لیستی نامحدود از موضوعات موردنظر خود اضافه کنید.
4. تولید محتوا را به‌صورت دستی اجرا کنید یا با استفاده از WP-Cron زمان‌بندی نمایید.
5. نگارنده به‌صورت خودکار:
   - مقاله کامل
   - عنوان
   - توضیحات سئو
   - دسته‌بندی
   - برچسب‌ها
   - تصویر شاخص
   
   را تولید کرده و در وردپرس ذخیره می‌کند.

# 💡 چرا نگارنده؟

نگارنده کنترل کامل فرآیند تولید محتوا با هوش مصنوعی را در اختیار شما قرار می‌دهد.

برخلاف ابزارهایی که از قالب‌های ثابت استفاده می‌کنند، شما می‌توانید پرامپت‌های اختصاصی خود را برای مقالات و تصاویر طراحی کنید و محتوایی مطابق با:

- سبک نوشتاری سایت
- استراتژی سئو
- حوزه کاری
- نیاز مخاطبان

تولید نمایید.

نگارنده کاملاً رایگان است، تنظیمات ساده‌ای دارد و با استفاده از کلید API اختصاصی شما به سرویس هوش مصنوعی موردنظر متصل می‌شود.
