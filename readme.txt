# Negarandeh – AI Content Generator for WordPress

**Negarandeh** is a free AI-powered WordPress plugin that automatically generates high-quality, SEO-friendly articles and featured images using your preferred AI provider via API. Simply provide a list of topics and custom prompts, and the plugin will create unique WordPress posts automatically.

Unlike many AI plugins, **Negarandeh is completely free** and includes **no subscriptions, no usage limits, and no in-app purchases**. You only need an API key from your preferred AI service.

## Features

- Unlimited AI-powered content generation
- Generate unique, SEO-friendly WordPress posts automatically
- Generate AI-powered featured images for every post
- Fully customizable article and image prompts
- Dynamic placeholders for flexible prompt templates
- Import unlimited topics and process them automatically
- Automatic topic queue processing with WP-Cron
- Manual or scheduled generation (1–5 minute intervals)
- Publish posts as Draft, Pending Review, or Published
- Automatically attach featured images to generated posts
- Compatible with Yoast SEO, Rank Math, All in One SEO, and other supported SEO plugins
- Automatically generate SEO metadata
- Automatic title, slug, excerpt, categories, and tags
- Detailed generation logs with token usage tracking
- Persian (Farsi) and English admin interface
- Supports multiple AI providers through API integration
- Lightweight, fast, and easy to use
- No subscriptions, no in-app purchases, and no plugin usage limits

## How It Works

1. Enter your AI provider API key.
2. Create custom prompts for articles and featured images.
3. Add an unlimited list of topics.
4. Start generation manually or schedule it with WP-Cron.
5. Negarandeh automatically generates complete SEO-friendly posts with featured images.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the **Plugins** menu in WordPress
3. Open **Negarandeh → API Settings** and enter your API key
4. Configure prompts and topics on the generator page, then press **Start**

== Frequently Asked Questions ==

= Does this plugin require an API key? =

Yes. An API key from a supported AI service provider is required.

= Can I run generation on a schedule? =

Yes. Enable periodic WP-Cron in the generator settings and press **Start** to allow runs.
